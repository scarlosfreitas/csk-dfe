Este é um projeto de uma Biblioteca para geração e decodificação de um Identificador de Partição Composta (Composite Sharding Key) de 64 bits pensado para documentos fiscais.

Leia integralmente todos os arquivos da pasta ./references

A pasta ./references contém a fonte da verdade dos dados.

A pasta notebooks não deve ser utilizada com referência. Ela será utilizada para criação de notebooks de teste.
 
Avalie o specs/PRD.md seguindo as melhores práticas de Spec Driven Development, manuais de utilização do OpenSpec.

Não faça nenhuma suposição que não possa ser deduzida desses arquivos. E me pergunte se ficar alguma lacuna.
